# IA — Cartões em Massa

Plugin pessoal do RemNote que transforma o texto selecionado em uma prévia editável de flashcards usando a API da OpenAI.

## Uso

1. Selecione um trecho em uma nota do RemNote.
2. Clique em **✨ Cartões em massa** no menu da seleção.
3. Na primeira utilização, importe o arquivo `.env.local` contendo `OPENAI_API_KEY`.
4. Gere os rascunhos, revise cada pergunta e resposta e desmarque o que não desejar.
5. Confirme **Criar cartões**. Os cards serão incluídos abaixo do Rem de origem.

A chave fica no armazenamento local do plugin e o ChatGPT não precisa estar aberto.
